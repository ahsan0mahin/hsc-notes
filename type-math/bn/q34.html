PQ→\overrightarrow{PQ} ভেক্টরের সমান্তরাল একটি একক ভেক্টর নির্ণয় করো।

মনে করি, PP বিন্দুর অবস্থান ভেক্টর OP⃗\vec{OP} এবং QQ বিন্দুর অবস্থান ভেক্টর OQ⃗\vec{OQ}। এবং OP⃗=2i^−j^+3k^OQ⃗\vec{OP} = 2\hat{i} - \hat{j} + 3\hat{k}\vec{OQ}

OP⃗=−2i^+2j^+k^\vec{OP} = -2\hat{i} + 2\hat{j} + \hat{k}
∴PQ⃗=OQ⃗−OP⃗\therefore \vec{PQ} = \vec{OQ} - \vec{OP}

PQ⃗=(−2i^+2j^+k^)−(2i^−j^+3k^)\vec{PQ} = (-2\hat{i} + 2\hat{j} + \hat{k}) - (2\hat{i} - \hat{j} + 3\hat{k})
PQ⃗=−2i^+2j^+k^−2i^+j^−3k^=−4i^+3j^−2k^\vec{PQ} = -2\hat{i} + 2\hat{j} + \hat{k} - 2\hat{i} + \hat{j} - 3\hat{k} = -4\hat{i} + 3\hat{j} - 2\hat{k} মনে করি, PQ⃗\vec{PQ} ভেক্টরের সমান্তরাল একটি একক ভেক্টর η^\hat{\eta}
η^=PQ⃗∣PQ⃗∣\hat{\eta} = \frac{\vec{PQ}}{|\vec{PQ}|}

η^=−4i^+3j^−2k^(−4)2+32+(−2)2\hat{\eta} = \frac{-4\hat{i} + 3\hat{j} - 2\hat{k}}{\sqrt{(-4)^2 + 3^2 + (-2)^2}}

η^=−4i^+3j^−2k^29\hat{\eta} = \frac{-4\hat{i} + 3\hat{j} - 2\hat{k}}{\sqrt{29}}

η^=−429i^+329j^−229k^\hat{\eta} = -\frac{4}{\sqrt{29}}\hat{i} + \frac{3}{\sqrt{29}}\hat{j} - \frac{2}{\sqrt{29}}\hat{k}
∴PQ⃗\therefore \vec{PQ} ভেক্টরের সমান্তরাল একটি একক ভেক্টর,
−429i^+329j^−229k^ Ans.-\frac{4}{\sqrt{29}}\hat{i} + \frac{3}{\sqrt{29}}\hat{j} - \frac{2}{\sqrt{29}}\hat{k}\text{ Ans.}
