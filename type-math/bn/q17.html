বস্তুকণার উপর OXOX বরাবর ক্রিয়াশীল লব্ধি বলের মান নির্ণয় করো।

ধরি, লব্ধি বল F⃗\vec{F}, OXOX এর দিকের সাথে θ\theta কোণ তৈরি করে।
OXOX এর সাথে F⃗1\vec{F}_1 এর কোণ, θ1=0∘\theta_1 = 0^\circ
OXOX এর সাথে F⃗2\vec{F}_2 এর কোণ, θ2=180∘−60∘=120∘\theta_2 = 180^\circ - 60^\circ = 120^\circ
OXOX এর সাথে F⃗3\vec{F}_3 এর কোণ, θ3=270∘−30∘=240∘\theta_3 = 270^\circ - 30^\circ = 240^\circ
∴\therefore বস্তুকণার উপর OXOX বরাবর ক্রিয়াশীল লব্ধি বলের মান,
Fx=∣F⃗∣cos⁡θF_x = |\vec{F}|\cos\theta

Fx=∣F⃗1∣cos⁡θ1+∣F⃗2∣cos⁡θ2+∣F⃗3∣cos⁡θ3F_x = |\vec{F}_1|\cos\theta_1 + |\vec{F}_2|\cos\theta_2 + |\vec{F}_3|\cos\theta_3
Fx=11cos⁡0∘+22cos⁡120∘+33cos⁡240∘F_x = 11\cos 0^\circ + 22\cos 120^\circ + 33\cos 240^\circ
Fx=−16.5 N Ans.F_x = -16.5\text{ N Ans.}
