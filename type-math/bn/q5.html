ON→\overrightarrow{ON} এর উপর OM→\overrightarrow{OM} এর লম্ব-অভিক্ষেপ নির্ণয় করো।

'গ' হতে পাই,
OM⃗=2i^+2j^−k^\vec{OM} = 2\hat{i} + 2\hat{j} - \hat{k}; ON⃗=6i^−3j^+2k^\vec{ON} = 6\hat{i} - 3\hat{j} + 2\hat{k} এখন,
MN⃗=ON⃗−OM⃗\vec{MN} = \vec{ON} - \vec{OM}

MN⃗=(6−2)i^+(−3−2)j^+(2+1)k^\vec{MN} = (6 - 2)\hat{i} + (-3 - 2)\hat{j} + (2 + 1)\hat{k}
MN⃗=4i^−5j^+3k^\vec{MN} = 4\hat{i} - 5\hat{j} + 3\hat{k}

∴∣OM⃗∣=(2)2+22+(−1)2\therefore |\vec{OM}| = \sqrt{(2)^2 + 2^2 + (-1)^2}

∣OM⃗∣=3|\vec{OM}| = 3
∣ON⃗∣=62+(−3)2+22|\vec{ON}| = \sqrt{6^2 + (-3)^2 + 2^2}

∣ON⃗∣=7|\vec{ON}| = 7 এবং ∣MN⃗∣=42+(−5)2+32=52|\vec{MN}| = \sqrt{4^2 + (-5)^2 + 3^2} = 5\sqrt{2} এখানে, ∣OM⃗∣2+∣ON⃗∣2=32+72=58|\vec{OM}|^2 + |\vec{ON}|^2 = 3^2 + 7^2 = 58 এবং ∣MN⃗∣2=(52)2=50|\vec{MN}|^2 = (5\sqrt{2})^2 = 50 অর্থাৎ, ∣MN⃗∣2≠∣OM⃗∣2+∣ON⃗∣2|\vec{MN}|^2 \neq |\vec{OM}|^2 + |\vec{ON}|^2
∴\therefore উদ্দীপকের ΔOMN\Delta OMN সমকোণী ত্রিভুজ হবে না।
