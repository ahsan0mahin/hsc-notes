  • দুটি সমান্তরাল আনুভূমিক পাড়ের মাঝে ABCDABCD সামান্তরিক আঁকা।
  • নিচের পাড়ে AA থেকে ডানদিকে BB পর্যন্ত স্রোত uu; AA থেকে ওপর-বামদিকে DD পর্যন্ত নৌকার বেগ vv; খাড়া ওপরের দিকে কর্ণ ACAC বরাবর লব্ধি বেগ RR (সমকোণ চিহ্নিত); এবং ABAB ও ADAD এর মধ্যবর্তী কোণ α\alpha।

আমরা জানি,
tan⁡θ=vsin⁡αu+vcos⁡α\tan\theta = \frac{v\sin\alpha}{u + v\cos\alpha}
বা, tan⁡90∘=6sin⁡α4+6cos⁡α\text{বা, } \tan 90^\circ = \frac{6\sin\alpha}{4 + 6\cos\alpha}
বা, 4+6cos⁡α=0\text{বা, } 4 + 6\cos\alpha = 0
বা, α=cos⁡−1(−46)∴α=131.81∘\text{বা, } \alpha = \cos^{-1}\left(\frac{-4}{6}\right) \therefore \alpha = 131.81^\circ
uu এবং vv এর লব্ধি,
R=u2+v2+2uvcos⁡α=42+62+2.4.6cos⁡(131.81)=25 ms−1R = \sqrt{u^2 + v^2 + 2uv\cos\alpha} = \sqrt{4^2 + 6^2 + 2.4.6\cos(131.81)} = 2\sqrt{5}\text{ ms}^{-1}
∴\therefore নৌকার লব্ধি বেগ, R=25 ms−1R = 2\sqrt{5}\text{ ms}^{-1} (Ans.)
