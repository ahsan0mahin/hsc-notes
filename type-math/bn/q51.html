AC⃗=(5−2)i^+(5−3)j^+(3−1)k^\vec{AC} = (5 - 2)\hat{i} + (5 - 3)\hat{j} + (3 - 1)\hat{k}

AC⃗=3i^+2j^+2k^\vec{AC} = 3\hat{i} + 2\hat{j} + 2\hat{k}
∴∣AC⃗∣=32+22+22\therefore |\vec{AC}| = \sqrt{3^2 + 2^2 + 2^2}

∣AC⃗∣=17|\vec{AC}| = \sqrt{17}
CB⃗=(8−5)i^+(7−5)j^+(5−3)k^\vec{CB} = (8 - 5)\hat{i} + (7 - 5)\hat{j} + (5 - 3)\hat{k}

CB⃗=3i^+2j^+2k^\vec{CB} = 3\hat{i} + 2\hat{j} + 2\hat{k}
∴∣CB⃗∣=17\therefore |\vec{CB}| = \sqrt{17}

প্রথম পথ (CC হয়ে AA থেকে BB): পথের মোট দূরত্ব, S1=∣AC⃗∣+∣CB⃗∣S_1 = |\vec{AC}| + |\vec{CB}|
∴S1=17+17\therefore S_1 = \sqrt{17} + \sqrt{17}

S1=217 mS_1 = 2\sqrt{17}\text{ m} এই পথে যাওয়ার সময় t1t_1 হলে,
t1=S1vt_1 = \frac{S_1}{v}

t1=21710  ⟹  ∴t1t_1 = \frac{2\sqrt{17}}{10} \implies \therefore t_1
