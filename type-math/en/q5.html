Hint Try it first

Full solution Diagram and explanation

We know, The perpendicular projection of B⃗\vec{B} on the vector A⃗\vec{A}, Bcos⁡θ=A⃗⋅B⃗∣A⃗∣B\cos\theta = \frac{\vec{A} \cdot \vec{B}}{|\vec{A}|} The perpendicular projection of OM→\overrightarrow{OM} on ∴ON→\therefore \overrightarrow{ON},
OMcos⁡θ=ON→⋅OM→∣ON→∣OM\cos\theta = \frac{\overrightarrow{ON} \cdot \overrightarrow{OM}}{|\overrightarrow{ON}|}

Part d · 4 marks

Hint Try it first

Checking the angle at O alone is insufficient. Test the longest side using all three squared lengths.

Full solution Diagram and explanation

From (c) we get,
OM→=2i^+2j^−k^\overrightarrow{OM} = 2\hat{i} + 2\hat{j} - \hat{k}; ON→=6i^−3j^+2k^\overrightarrow{ON} = 6\hat{i} - 3\hat{j} + 2\hat{k} Now,
MN→=ON→−OM→\overrightarrow{MN} = \overrightarrow{ON} - \overrightarrow{OM}

MN→=(6−2)i^+(−3−2)j^+(2+1)k^\overrightarrow{MN} = (6 - 2)\hat{i} + (-3 - 2)\hat{j} + (2 + 1)\hat{k}
MN→=4i^−5j^+3k^\overrightarrow{MN} = 4\hat{i} - 5\hat{j} + 3\hat{k}

∴∣OM→∣=(2)2+22+(−1)2\therefore |\overrightarrow{OM}| = \sqrt{(2)^2 + 2^2 + (-1)^2}

∣OM→∣=3|\overrightarrow{OM}| = 3
∣ON→∣=62+(−3)2+22|\overrightarrow{ON}| = \sqrt{6^2 + (-3)^2 + 2^2}

∣ON→∣=7|\overrightarrow{ON}| = 7 Here, ∣MN→∣=42+(−5)2+32=52|\overrightarrow{MN}| = \sqrt{4^2 + (-5)^2 + 3^2} = 5\sqrt{2} here, ∣OM→∣2+∣ON→∣2=32+72=58|\overrightarrow{OM}|^2 + |\overrightarrow{ON}|^2 = 3^2 + 7^2 = 58 Here, ∣MN→∣2=(52)2=50|\overrightarrow{MN}|^2 = (5\sqrt{2})^2 = 50 Therefore, ∣MN→∣2≠∣OM→∣2+∣ON→∣2|\overrightarrow{MN}|^2 \neq |\overrightarrow{OM}|^2 + |\overrightarrow{ON}|^2
