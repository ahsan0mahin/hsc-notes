River–boat and current

Question 26

Barishal Board · 2024 · Board question no. 1 · book p. 43

One swimmer starts swimming with velocity 16 kmh−116\text{ kmh}^{-1} at an angle 10∘10^\circ with ABAB. The velocity of the current in the river is 8 kmh−18\text{ kmh}^{-1}. Another swimmer starts swimming in the same river with the same speed at an angle 60∘60^\circ with the current.

Part c · 3 marks

The first swimmer set off along ACAC in order to reach point BB and reached point DD; determine the distance BDBD.

Hint Try it first

The 10° angle is measured from the width. Decide which component uses sine and which uses cosine.

Full solution Diagram and explanation

BD=(8−16sin⁡10∘)2016cos⁡10∘ kmBD=(8-16\sin10^\circ)\frac{20}{16\cos10^\circ}\,\mathrm{km}

Time is 20/(16 cos10°) h. Downstream speed is 8−16 sin10°; multiplying gives about 6.63 km.

Part d · 4 marks

Between the two swimmers, which swimmer will reach the other bank first? Analyse mathematically.

Hint Try it first

The second swimmer’s 60° is measured from downstream, not from the width.

Full solution Diagram and explanation

t1=2016cos⁡10∘<t2=2016sin⁡60∘t_1=\frac{20}{16\cos10^\circ}<t_2=\frac{20}{16\sin60^\circ}

The times are 1.27 h and 20/(16 sin60°)≈1.44 h respectively. The first swimmer arrives earlier.
