River–boat and current

Question 1

Mymensingh Board · 2025 · Board question no. 1 · book p. 29

In a boat-racing competition, Karim set off from point OO along OAOA and reached point BB with a velocity of 5.3 kmh−15.3\text{ kmh}^{-1}. But Rahim set off along OBOB and, crossing the river in the stipulated time, reached point RR. During the race, rain suddenly began to fall with a velocity of 10 kmh−110\text{ kmh}^{-1}. In both cases the speed of the boat was 5 kmh−15\text{ kmh}^{-1}.

Part c · 3 marks

Determine in how much time Rahim crossed the river.

Hint Try it first

Use the component along OB, not the length of OR. Divide the width by this component and convert hours to minutes.

Full solution Diagram and explanation

We know, If the boat is rowed along the width of the river
time, t=dvsin⁡α\text{time, } t = \frac{d}{v\sin\alpha}
25sin⁡90∘\frac{2}{5\sin 90^\circ}
time, t=0.4 h\text{time, } t = 0.4\text{ h}
time, t=24 min Ans.\text{time, } t = 24\text{ min Ans.}

Part d · 4 marks

According to the stem, at what angle must Karim hold the umbrella to be saved from the rain? Explain mathematically.

Hint Try it first

Draw the vertical rain velocity and subtract Karim’s horizontal ground velocity. Which angle is measured from vertical?

Full solution Diagram and explanation

If the actual velocity of the rain is inclined at an angle θ\theta with the vertical,
tan⁡θ=uw\tan\theta = \frac{u}{w}
∴θ=tan⁡−1uw\therefore \theta = \tan^{-1}\frac{u}{w}

θ=tan⁡−1(5.310)\theta = \tan^{-1}\left(\frac{5.3}{10}\right)
θ=27.92∘ (with the vertical direction)\theta = 27.92^\circ \text{ (with the vertical direction)}

∴\therefore Karim must hold the umbrella at an angle 27.92∘27.92^\circ with the vertical to be saved from the rain.
