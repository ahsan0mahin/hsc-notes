River–boat and current

Question 40

Chattogram Board · 2021 · Board question no. 2 · book p. 50

Shanta is a college student. A river 1 km1\text{ km} wide flows past his house. His college is straight across on the other bank. One morning, 55 minutes before class was to begin, he set off for college in a boat with velocity 12 kmh−112\text{ kmh}^{-1} at an angle 120∘120^\circ with the direction of the current.

Part c · 3 marks

Determine the velocity of the current in the river.

Hint Try it first

A direct landing requires the horizontal component of the ground velocity to vanish.

Full solution Diagram and explanation

We know,
tan⁡θ=vsin⁡αu+vcos⁡α\tan\theta = \frac{v\sin\alpha}{u + v\cos\alpha}
or, tan⁡90∘=12sin⁡120∘u+12cos⁡120∘\text{or, } \tan 90^\circ = \frac{12\sin 120^\circ}{u + 12\cos 120^\circ}
or, u+12cos⁡120∘=0\text{or, } u + 12\cos 120^\circ = 0
or, u=−12cos⁡120∘\text{or, } u = -12\cos 120^\circ
∴u=6 kmh−1 Ans.\therefore u = 6\text{ kmh}^{-1}\text{ Ans.}

Part d · 4 marks

Will Shanta be able to attend class on time? Analyse mathematically.

Hint Try it first

The current cannot increase the perpendicular component. Convert the resulting time to minutes.

Full solution Diagram and explanation

Let, Shanta will be able to cross the river in a time tt.
∴\therefore component of the boat's velocity along the width of the river = vsin⁡α=12×sin⁡120∘=63 kmh−1v\sin\alpha = 12 \times \sin 120^\circ = 6\sqrt{3}\text{ kmh}^{-1}
Therefore, the time required to cross the river,
t=dvsin⁡αt = \frac{d}{v\sin\alpha}

t=1 km63 kmh−1t = \frac{1\text{ km}}{6\sqrt{3}\text{ kmh}^{-1}}

t=163×60 mint = \frac{1}{6\sqrt{3}} \times 60\text{ min}
∴t=5.774 min>5 min\therefore t = 5.774\text{ min} > 5\text{ min} Therefore, if Shanta sets off 55 minutes before class begins, it will take her 5.7745.774 minutes to cross the river. That is, she will not be able to attend class on time.
