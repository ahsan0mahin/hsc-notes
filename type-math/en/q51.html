Barishal Cadet College · Board question no. 1 · book p. 56

A drone delivery company uses drones to deliver packages in a city. The drone starts from a warehouse located at A(2,3,1)A(2, 3, 1) and has to reach a customer located at B(8,7,5)B(8, 7, 5). However, because of a multi-storey building in between, the drone first has to pass through a checkpoint C(5,5,3)C(5, 5, 3) on the roof of the building and then reach the customer.

Part c · 3 marks

Determine the angle between the vectors ACAC and CBCB.

Hint Try it first

Are the displacements from A to C and from C to B proportional?

Full solution Diagram and explanation

AC→=CB→=(3,2,2)\overrightarrow{AC}=\overrightarrow{CB}=(3,2,2)

AC=CB=(3,2,2). The vectors have the same direction: θ=0°.

Part d · 4 marks

If the drone moves with uniform velocity 10 m/s10\text{ m/s}, analyse mathematically whether the total time to go from AA to BB via CC will be less than the time to go directly from AA to BB.

Hint Try it first

Compare the sum of the segment lengths with the direct distance before dividing by speed.

Full solution Diagram and explanation

AC→=(5−2)i^+(5−3)j^+(3−1)k^\overrightarrow{AC} = (5 - 2)\hat{i} + (5 - 3)\hat{j} + (3 - 1)\hat{k}

AC→=3i^+2j^+2k^\overrightarrow{AC} = 3\hat{i} + 2\hat{j} + 2\hat{k}
∴∣AC→∣=32+22+22\therefore |\overrightarrow{AC}| = \sqrt{3^2 + 2^2 + 2^2}

∣AC→∣=17|\overrightarrow{AC}| = \sqrt{17}
CB→=(8−5)i^+(7−5)j^+(5−3)k^\overrightarrow{CB} = (8 - 5)\hat{i} + (7 - 5)\hat{j} + (5 - 3)\hat{k}

CB→=3i^+2j^+2k^\overrightarrow{CB} = 3\hat{i} + 2\hat{j} + 2\hat{k}
∴∣CB→∣=17\therefore |\overrightarrow{CB}| = \sqrt{17}

First path (from AA to BB via CC): Total distance of the path, S1=∣AC→∣+∣CB→∣S_1 = |\overrightarrow{AC}| + |\overrightarrow{CB}|
∴S1=17+17\therefore S_1 = \sqrt{17} + \sqrt{17}

S1=217 mS_1 = 2\sqrt{17}\text{ m} Velocity of the boat with the current t1t_1
t1=S1vt_1 = \frac{S_1}{v}

t1=21710t_1 = \frac{2\sqrt{17}}{10}

t1=0.825 st_1 = 0.825\text{ s}

Second path (directly from AA to BB):
AB→=(8−2)i^+(7−3)j^+(5−1)k^\overrightarrow{AB} = (8 - 2)\hat{i} + (7 - 3)\hat{j} + (5 - 1)\hat{k}

AB→=6i^+4j^+4k^\overrightarrow{AB} = 6\hat{i} + 4\hat{j} + 4\hat{k} Distance along this path, S2=∣AB→∣S_2 = |\overrightarrow{AB}|
S2=62+42+42S_2 = \sqrt{6^2 + 4^2 + 4^2}

S2=36+16+16S_2 = \sqrt{36 + 16 + 16}

S2=68 mS_2 = \sqrt{68}\text{ m}

S2=217 mS_2 = 2\sqrt{17}\text{ m} Velocity of the boat with the current t2t_2
t2=S2vt_2 = \frac{S_2}{v}

t2=21710t_2 = \frac{2\sqrt{17}}{10}

t2=0.825 st_2 = 0.825\text{ s} It is seen that the time taken is the same in both cases (t1=t2t_1 = t_2). Therefore, the total time to go from AA to BB via CC will not be less than the time to go directly from AA to BB; rather it will be equal.
