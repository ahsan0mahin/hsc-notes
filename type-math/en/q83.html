River–boat and current

Question 83

Cantonment College, Jashore · Board question no. 1 · book p. 71

In the figure, in a river whose current flows with velocity 1.1 ms−11.1\text{ ms}^{-1}, a boat of velocity 2.3 ms−12.3\text{ ms}^{-1} is rowed along OPOP and reaches position QQ. While the boat was moving, rain began to fall vertically with velocity 4.2 ms−14.2\text{ ms}^{-1}.

Part c · 3 marks

Determine at what angle with the vertical the boatman must hold the umbrella to be saved from the rain.

Hint Try it first

Combine the two horizontal boat components before comparing them with vertical rain speed.

Full solution Diagram and explanation

Resultant velocity of the boat (relative to the ground),
VB⃗=u⃗+v⃗\vec{V_B} = \vec{u} + \vec{v}

VB⃗=(1.1i^+2.3j^) ms−1\vec{V_B} = (1.1\hat{i} + 2.3\hat{j})\text{ ms}^{-1} Velocity of the rain relative to the passenger,
VR/B⃗=VR⃗−VB⃗\vec{V_{R/B}} = \vec{V_R} - \vec{V_B}

VR/B⃗=(−4.2j^)−(1.1i^+2.3j^)\vec{V_{R/B}} = (-4.2\hat{j}) - (1.1\hat{i} + 2.3\hat{j})
or, VR/B⃗=−1.1i^−6.5j^ ms−1\text{or, } \vec{V_{R/B}} = -1.1\hat{i} - 6.5\hat{j}\text{ ms}^{-1} Horizontal component of the relative velocity, Vx=1.1 ms−1V_x = 1.1\text{ ms}^{-1} Vertical component of the relative velocity, Vy=6.5 ms−1V_y = 6.5\text{ ms}^{-1} Let the boatman have to hold the umbrella at an angle θ\theta with the vertical to be saved from the rain. We know,
tan⁡θ=horizontal componentvertical component\tan\theta = \frac{\text{horizontal component}}{\text{vertical component}}

tan⁡θ=VxVy\tan\theta = \frac{V_x}{V_y}

tan⁡θ=1.16.5\tan\theta = \frac{1.1}{6.5}
or, θ=tan⁡−1(1.16.5)\text{or, } \theta = \tan^{-1}\left(\frac{1.1}{6.5}\right)

or, θ=9.59∘ Ans.\text{or, } \theta = 9.59^\circ\text{ Ans.}

Part d · 4 marks

Analyse mathematically whether the boat could cross the river in even less time if it were rowed along OQOQ with the same velocity.

Hint Try it first

The starting heading is already normal to the shore. Compare the new heading’s perpendicular component.

Full solution Diagram and explanation

In the 1st case, Since the man initially sets off along OPOP, the angle with the current is α=90∘\alpha = 90^\circ. In this case, the time required to cross the river,
t1=dusin⁡αt_1 = \frac{d}{u\sin\alpha}

t1=14002.3sin⁡90∘t_1 = \frac{1400}{2.3\sin 90^\circ}

t1=608.7 st_1 = 608.7\text{ s}

t1=10.145 mint_1 = 10.145\text{ min}

(lower box) Here, Velocity of the boat, u=2.3 ms−1u = 2.3\text{ ms}^{-1} Velocity of the current, v=1.1 ms−1v = 1.1\text{ ms}^{-1} Width of the river, d=1.4 km=1400md = 1.4\text{ km} = 1400\text{m}
The resultant velocity of the boat WW is along OQOQ and it makes an angle θ\theta with OPOP.
now, tan⁡θ=vu\text{now, } \tan\theta = \frac{v}{u}

now, tan⁡θ=1.12.3\text{now, } \tan\theta = \frac{1.1}{2.3}

now, tan⁡θ=0.4783\text{now, } \tan\theta = 0.4783
∴θ=tan⁡−1(0.4783)\therefore \theta = \tan^{-1}(0.4783)

θ=25.56∘\theta = 25.56^\circ
