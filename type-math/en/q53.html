Question 53

Notre Dame College, Dhaka · Board question no. 1 · book p. 57

The magnitudes of P⃗,Q⃗\vec{P}, \vec{Q} and R⃗\vec{R} are 3,43, 4 and 55 respectively, and P⃗+Q⃗+R⃗=0\vec{P} + \vec{Q} + \vec{R} = 0.

Part c · 3 marks

Determine Q⃗⋅R⃗\vec{Q} \cdot \vec{R}.

Hint Try it first

Rearrange the closed-vector equation to isolate P, then square using the dot product.

Full solution Diagram and explanation

according to the stem,
P⃗+Q⃗+R⃗=0\vec{P} + \vec{Q} + \vec{R} = 0
or, P⃗=−(Q⃗+R⃗)\text{or, } \vec{P} = -(\vec{Q} + \vec{R}) Squaring both sides we get,
∣P⃗∣2=∣−(Q⃗+R⃗)∣2|\vec{P}|^2 = |-(\vec{Q} + \vec{R})|^2
or, P2=∣(Q⃗+R⃗)∣2\text{or, } P^2 = |(\vec{Q} + \vec{R})|^2
or, P2=Q2+R2+2Q⃗⋅R⃗\text{or, } P^2 = Q^2 + R^2 + 2\vec{Q} \cdot \vec{R}
or, 32=42+52+2(Q⃗⋅R⃗)\text{or, } 3^2 = 4^2 + 5^2 + 2(\vec{Q} \cdot \vec{R})
or, 9=41+2(Q⃗⋅R⃗)\text{or, } 9 = 41 + 2(\vec{Q} \cdot \vec{R})
or, 2(Q⃗⋅R⃗)=9−41\text{or, } 2(\vec{Q} \cdot \vec{R}) = 9 - 41

or, 2(Q⃗⋅R⃗)=−32\text{or, } 2(\vec{Q} \cdot \vec{R}) = -32
∴Q⃗⋅R⃗=−16 Ans.\therefore \vec{Q} \cdot \vec{R} = -16\text{ Ans.}

Part d · 4 marks

Can the value of R⃗×(P⃗×Q⃗)\vec{R} \times (\vec{P} \times \vec{Q}) be determined? Analyse mathematically.

Hint Try it first

Use the given side lengths to test the angle between P and Q. Where does R lie relative to P×Q?

Full solution Diagram and explanation

∣R⃗×(P⃗×Q⃗)∣=5(3)(4)=60|\vec R\times(\vec P\times\vec Q)|=5(3)(4)=60

Since 3²+4²=5², P and Q are perpendicular; their cross product has length 12. R lies in their plane, so it is perpendicular to P×Q. The required magnitude is 5×12=60.
