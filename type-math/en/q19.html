Part c · 3 marks

Determine for what value of aa the field of the vector r⃗\vec{r} will be solenoidal.

Hint Try it first

Set the sum of matching component derivatives to the solenoidal condition.

Full solution Diagram and explanation

If the field is solenoidal, the divergence of the vector r⃗\vec{r} will be zero. that is, ∇⃗⋅r⃗=0\vec{\nabla} \cdot \vec{r} = 0 or, (i^∂∂x+j^∂∂y+k^∂∂z)⋅(axi^+yj^+2k^)=0\left(\hat{i}\frac{\partial}{\partial x} + \hat{j}\frac{\partial}{\partial y} + \hat{k}\frac{\partial}{\partial z}\right) \cdot (ax\hat{i} + y\hat{j} + 2\hat{k}) = 0 or, ∂∂x(ax)+∂∂y(y)+∂∂z(2)=0\frac{\partial}{\partial x}(ax) + \frac{\partial}{\partial y}(y) + \frac{\partial}{\partial z}(2) = 0 or, a+1+0=0a + 1 + 0 = 0
∴a=−1\therefore a = -1 Therefore, if the value of aa is −1-1, the field of the vector r⃗\vec{r} will be solenoidal. Ans.

Part d · 4 marks

Full solution Diagram and explanation

The rotational character of a vector field depends on its curl. If the curl of a vector is zero, that vector is irrotational and conservative. Otherwise, the vector will be rotational and non-conservative. Now,

−19i^+18j^−4k^-19\hat{i} + 18\hat{j} - 4\hat{k}
