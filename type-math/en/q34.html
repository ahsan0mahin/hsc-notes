Part c · 3 marks

Determine a unit vector parallel to the vector PQ→\overrightarrow{PQ}.

Hint Try it first

Subtract P from Q and normalize the resulting displacement.

Full solution Diagram and explanation

A position vector and a differential vector operator are denoted by PP and OP→\overrightarrow{OP} respectively.
OP→=2i^−j^+3k^ and OQ→\overrightarrow{OP} = 2\hat{i} - \hat{j} + 3\hat{k}\text{ and }\overrightarrow{OQ}

OP→=−2i^+2j^+k^\overrightarrow{OP} = -2\hat{i} + 2\hat{j} + \hat{k}
∴PQ→=OQ→−OP→\therefore \overrightarrow{PQ} = \overrightarrow{OQ} - \overrightarrow{OP}

PQ→=(−2i^+2j^+k^)−(2i^−j^+3k^)\overrightarrow{PQ} = (-2\hat{i} + 2\hat{j} + \hat{k}) - (2\hat{i} - \hat{j} + 3\hat{k})
−2i^+2j^+k^−2i^+j^−3k^=−4i^+3j^−2k^-2\hat{i} + 2\hat{j} + \hat{k} - 2\hat{i} + \hat{j} - 3\hat{k} = -4\hat{i} + 3\hat{j} - 2\hat{k} Let a unit vector parallel to the vector PQ→\overrightarrow{PQ} be η^\hat{\eta}
η^=PQ→∣PQ→∣\hat{\eta} = \frac{\overrightarrow{PQ}}{|\overrightarrow{PQ}|}

η^=−4i^+3j^−2k^(−4)2+32+(−2)2\hat{\eta} = \frac{-4\hat{i} + 3\hat{j} - 2\hat{k}}{\sqrt{(-4)^2 + 3^2 + (-2)^2}}

η^=−4i^+3j^−2k^29\hat{\eta} = \frac{-4\hat{i} + 3\hat{j} - 2\hat{k}}{\sqrt{29}}

η^=−429i^+329j^−229k^\hat{\eta} = -\frac{4}{\sqrt{29}}\hat{i} + \frac{3}{\sqrt{29}}\hat{j} - \frac{2}{\sqrt{29}}\hat{k} A unit vector parallel to the vector ∴PQ→\therefore \overrightarrow{PQ},
−429i^+329j^−229k^ Ans.-\frac{4}{\sqrt{29}}\hat{i} + \frac{3}{\sqrt{29}}\hat{j} - \frac{2}{\sqrt{29}}\hat{k}\text{ Ans.}
