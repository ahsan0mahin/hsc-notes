Gradient–divergence–curl

Question 46

Rajshahi Cadet College · Board question no. 1 · book p. 54

A position vector and a differential vector operator are denoted by r⃗=xi^+yj^+zk^\vec{r} = x\hat{i} + y\hat{j} + z\hat{k} and ∇⃗=(∂∂xi^+∂∂yj^+∂∂zk^)\vec{\nabla} = \left(\frac{\partial}{\partial x}\hat{i} + \frac{\partial}{\partial y}\hat{j} + \frac{\partial}{\partial z}\hat{k}\right) respectively.

[printed as r in the book]

Part c · 3 marks

Determine the value of ∇⃗(1r)\vec{\nabla}\left(\frac{1}{r}\right).

Hint Try it first

Write 1/r as a power of x²+y²+z² before differentiating.

Full solution Diagram and explanation

We know,

<div class="math">∇⃗(1r)=(i^∂∂x+j^∂∂y+k^∂∂z)⋅(x2+y2+z2)−1/2.[dot symbol of the original]\vec\nabla\left(\frac1r\right)=\left(\hat i\frac{\partial}{\partial x}+\hat j\frac{\partial}{\partial y}+\hat k\frac{\partial}{\partial z}\right)\cdot(x^2+y^2+z^2)^{-1/2}.\quad\text{[dot symbol of the original]}</div>
Here, the position vector r⃗=xi^+yj^+zk^\vec r=x\hat i+y\hat j+z\hat k; the magnitude of the vector r=x2+y2+z2r=\sqrt{x^2+y^2+z^2}; the differential operator,

∇⃗=i^∂∂x+j^∂∂y+k^∂∂z.\vec\nabla=\hat i\frac{\partial}{\partial x}+\hat j\frac{\partial}{\partial y}+\hat k\frac{\partial}{\partial z}.
Now, differentiating with respect to x we get,

∂∂x(x2+y2+z2)−1/2=−12(x2+y2+z2)−3/2⋅2x=−x(x2+y2+z2)3/2\frac{\partial}{\partial x}(x^2+y^2+z^2)^{-1/2}=-\frac12(x^2+y^2+z^2)^{-3/2}\cdot2x=-\frac{x}{(x^2+y^2+z^2)^{3/2}}

∴∂∂x(1r)=−xr3.\therefore\frac{\partial}{\partial x}\left(\frac1r\right)=-\frac{x}{r^3}.
similarly,

∂∂y(1r)=−yr3and∂∂z(1r)=−zr3.\frac{\partial}{\partial y}\left(\frac1r\right)=-\frac{y}{r^3}\quad\text{and}\quad\frac{\partial}{\partial z}\left(\frac1r\right)=-\frac{z}{r^3}.
Now, putting in the values we get,

∇⃗(1r)=i^(−xr3)+j^(−yr3)+k^(−zr3)\vec\nabla\left(\frac1r\right)=\hat i\left(-\frac{x}{r^3}\right)+\hat j\left(-\frac{y}{r^3}\right)+\hat k\left(-\frac{z}{r^3}\right)
or,

∇⃗(1r)=−1r3(xi^+yj^+zk^)\vec\nabla\left(\frac1r\right)=-\frac1{r^3}(x\hat i+y\hat j+z\hat k)

∴∇⃗(1r)=−r⃗r3.(Ans.)\therefore\vec\nabla\left(\frac1r\right)=-\frac{\vec r}{r^3}.\quad(\mathrm{Ans.})

Part d · 4 marks

Determine the value of ∇⃗×(r⃗r2)\vec{\nabla} \times \left(\frac{\vec{r}}{r^2}\right) according to the stem. Is it rotational (Rotational\text{Rotational}) or irrotational? Explain mathematically.

Hint Try it first

Can the field be expressed as a gradient away from the origin?

Full solution Diagram and explanation

let, V⃗=r⃗r2=xi^+yj^+zk^x2+y2+z2\vec{V} = \frac{\vec{r}}{r^2} = \frac{x\hat{i} + y\hat{j} + z\hat{k}}{x^2 + y^2 + z^2} here, Vx=xx2+y2+z2V_x = \frac{x}{x^2 + y^2 + z^2}
Vy=yx2+y2+z2V_y = \frac{y}{x^2 + y^2 + z^2}
Vz=zx2+y2+z2V_z = \frac{z}{x^2 + y^2 + z^2}
Now,
∇⃗×V⃗=∣i^j^k^∂∂x∂∂y∂∂zVxVyVz∣\vec{\nabla} \times \vec{V} = \left|\begin{matrix} \hat{i} & \hat{j} & \hat{k} \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ V_x & V_y & V_z \end{matrix}\right| coefficient of i^\hat{i} = ∂Vz∂y−∂Vy∂z=∂∂y(zx2+y2+z2)−∂∂z(yx2+y2+z2)\frac{\partial V_z}{\partial y} - \frac{\partial V_y}{\partial z} = \frac{\partial}{\partial y}\left(\frac{z}{x^2 + y^2 + z^2}\right) - \frac{\partial}{\partial z}\left(\frac{y}{x^2 + y^2 + z^2}\right) or, ∂Vz∂y−∂Vy∂z=z(−2y(x2+y2+z2)2)−y(−2z(x2+y2+z2)2)\frac{\partial V_z}{\partial y} - \frac{\partial V_y}{\partial z} = z\left(-\frac{2y}{(x^2 + y^2 + z^2)^2}\right) - y\left(-\frac{2z}{(x^2 + y^2 + z^2)^2}\right)
∴∂Vz∂y−∂Vy∂z=−2yzr4+2yzr4=0\therefore \frac{\partial V_z}{\partial y} - \frac{\partial V_y}{\partial z} = -\frac{2yz}{r^4} + \frac{2yz}{r^4} = 0 Similarly it is seen that the coefficients of j^\hat{j} and k^\hat{k} will also be zero.
∂Vx∂z−∂Vz∂x=0\frac{\partial V_x}{\partial z} - \frac{\partial V_z}{\partial x} = 0
and, ∂Vy∂x−∂Vx∂y=0\text{and, } \frac{\partial V_y}{\partial x} - \frac{\partial V_x}{\partial y} = 0
∴∇⃗×(r⃗r2)=0i^+0j^+0k^=0⃗\therefore \vec{\nabla} \times \left(\frac{\vec{r}}{r^2}\right) = 0\hat{i} + 0\hat{j} + 0\hat{k} = \vec{0} Since a vector field is irrotational when its curl is zero, and since the value of ∇⃗×(r⃗r2)\vec{\nabla} \times \left(\frac{\vec{r}}{r^2}\right) in the stem is zero, it is an irrotational vector.
