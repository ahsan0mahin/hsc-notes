সরাসরি B-তে যেতে উজান উপাংশ 6 km/h লাগবে। প্রস্থ বরাবর বেগ √108 km/h, তাই সময় (4/√108) × 60 ≈ 23.1 min > 20 min। সাক্ষাৎ হবে না।

  • সমান্তরাল দুটি পাড়: নিচে AA, ওপরে ঠিক বিপরীতে BB।
  • AA থেকে ডানদিকে স্রোত PP, খাড়া ওপরের দিকে BB অভিমুখে লব্ধি RR (সমকোণ 90∘90^\circ চিহ্নিত), এবং ওপর-বামদিকে তির্যকভাবে নৌকার বেগ QQ।

(ডান পাশের বক্স)
এখানে,

  • নদীর প্রস্থ d=4 kmd = 4\text{ km}
  • স্রোতের বেগ, P=6 kmh−1P = 6\text{ kmh}^{-1}
  • নৌকার বেগ, Q=12 kmh−1Q = 12\text{ kmh}^{-1}
  • ধরা যাক, এদের লব্ধি RR
  • P⃗\vec{P} ও Q⃗\vec{Q} এর মধ্যবর্তী কোণ α\alpha এবং
  • R⃗\vec{R} ও P⃗\vec{P} এর মধ্যবর্তী কোণ, θ=90∘\theta = 90^\circ

আমরা জানি,
tan⁡θ=Qsin⁡αP+Qcos⁡α\tan\theta = \frac{Q\sin\alpha}{P + Q\cos\alpha}
বা, tan⁡90∘=10=Qsin⁡αP+Qcos⁡α\text{বা, } \tan 90^\circ = \frac{1}{0} = \frac{Q\sin\alpha}{P + Q\cos\alpha}
বা, P+Qcos⁡α=0\text{বা, } P + Q\cos\alpha = 0
বা, cos⁡α=(−PQ)\text{বা, } \cos\alpha = \left(-\frac{P}{Q}\right)
বা, α=cos⁡−1(−612)=cos⁡−1(−12)=120∘\text{বা, } \alpha = \cos^{-1}\left(-\frac{6}{12}\right) = \cos^{-1}\left(-\frac{1}{2}\right) = 120^\circ
∴লব্ধি, R=P2+Q2+2PQcos⁡α=62+122+2×6×12(−12)=180−72=63 kmh−1\therefore \text{লব্ধি, } R = \sqrt{P^2 + Q^2 + 2PQ\cos\alpha} = \sqrt{6^2 + 12^2 + 2 \times 6 \times 12\left(-\frac{1}{2}\right)} = \sqrt{180 - 72} = 6\sqrt{3}\text{ kmh}^{-1}
এখানে, নৌকাটির অপর পাড়ে BB বিন্দুতে যেতে t hourt\text{ hour} সময় লাগলে,
t=dR=463 h=0.385 h=23.1 min>20 mint = \frac{d}{R} = \frac{4}{6\sqrt{3}}\text{ h} = 0.385\text{ h} = 23.1\text{ min} > 20\text{ min}
গাণিতিক বিশ্লেষণে দেখা যাচ্ছে যে নৌকাটির অপর পাড়ে যেতে যে সময় লাগে তার অনেক আগেই BB বিন্দুতে অপেক্ষমান লোকটি চলে যাবে তাই নৌকাটির সাথে তার সাক্ষাৎ হবে না।
