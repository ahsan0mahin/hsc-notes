হিন্ট আগে নিজে চেষ্টা করো
পূর্ণ উত্তর চিত্র ও সমাধান

ধরি, নদীতে নৌকার বেগ v⃗\vec{v} এবং স্রোতের বেগ u⃗\vec{u} এবং নৌকাটিকে স্রোতের সাথে α\alpha কোণে চালনা করলে নৌকাটি আড়াআড়িভাবে নদী পার হবে। অর্থাৎ লব্ধির দিক স্রোতের সাথে 90∘90^\circ হবে।
আমরা জানি, লব্ধির দিক, tan⁡θ=vsin⁡αu+vcos⁡α\tan\theta = \frac{v\sin\alpha}{u + v\cos\alpha}
বা, cot⁡θ=u+vcos⁡αvsin⁡α\text{বা, } \cot\theta = \frac{u + v\cos\alpha}{v\sin\alpha}
বা, cot⁡90∘=u+vcos⁡αvsin⁡α\text{বা, } \cot 90^\circ = \frac{u + v\cos\alpha}{v\sin\alpha}
বা, u+vcos⁡α=0\text{বা, } u + v\cos\alpha = 0
বা, vcos⁡α=−u\text{বা, } v\cos\alpha = -u
বা, cos⁡α=(−uv)\text{বা, } \cos\alpha = \left(\frac{-u}{v}\right)
বা, α=cos⁡−1(−uv)\text{বা, } \alpha = \cos^{-1}\left(\frac{-u}{v}\right)
অর্থাৎ, নৌকাটিকে আড়াআড়িভাবে নদী পাড়ি দিতে স্রোতের সাথে cos⁡−1(−uv)\cos^{-1}\left(-\frac{u}{v}\right) কোণে নৌকা চালনা করতে হবে।

[যাচাই-সংযোজন ২৯; মূল বইয়ে গ–ঘ-এর শুধু ওপরের নির্দেশ ও ফল] P⃗⋅Q⃗=5+3−4m=0⇒m=2\vec P\cdot\vec Q=5+3-4m=0\Rightarrow m=2। নৌকার বেগের মান 38\sqrt{38} এবং স্রোতের মান 18\sqrt{18}। ন্যূনতম পথে প্রস্থ-বরাবর বেগ 38−18=20\sqrt{38-18}=\sqrt{20}। মূলের দৈর্ঘ্যগুলোর হিসাব সময় 2-কে সরাসরি বসিয়ে করা হয়েছে; এতে বেগের সময়ের একক মিনিট ধরে নিতে হয়। দশমিক আগেভাগে না ছাঁটলে দ্বিতীয় দৈর্ঘ্য প্রায় 10.8579, অর্থাৎ 10.86 একক (মূলের 10.84-এর সামান্য বিচ্যুতি আছে)। বেগের একক m s⁻¹ হলে সময় 120 s বসাতে হবে এবং দৈর্ঘ্যগুলো 60 গুণ হবে। উদ্দীপকে বেগের একক অনুল্লিখিত।
