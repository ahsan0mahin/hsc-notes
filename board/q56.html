অংশ খ　·　২ নম্বর

দুটি অসমান সমজাতীয় ভেক্টরের লব্ধি শূন্য হতে পারে কী? ব্যাখ্যা করো।

হিন্ট আগে নিজে চেষ্টা করো
পূর্ণ উত্তর চিত্র ও সমাধান

দুটি অসমান সমজাতীয় ভেক্টরের লব্ধি শূন্য হতে পারে না।
মনে করি, P⃗\vec{P} ও Q⃗\vec{Q} দুটি অসমান সমজাতীয় ভেক্টর এবং এদের মধ্যবর্তী কোণ α\alpha। এদের লব্ধির মান RR হলে,
R=P2+Q2+2PQcos⁡αR = \sqrt{P^2 + Q^2 + 2PQ\cos\alpha}
লব্ধির মান সর্বনিম্ন হয় যখন α=180∘\alpha = 180^\circ হয়। এই ক্ষেত্রে লব্ধির ন্যূনতম মান হবে,
Rmin⁡=P2+Q2+2PQcos⁡180∘=P2+Q2−2PQ=(P−Q)2R_{\min} = \sqrt{P^2 + Q^2 + 2PQ\cos 180^\circ} = \sqrt{P^2 + Q^2 - 2PQ} = \sqrt{(P - Q)^2}
বা, Rmin⁡=∣P−Q∣\text{বা, } R_{\min} = |P - Q|
লব্ধি শূন্য হওয়ার জন্য, Rmin⁡=0R_{\min} = 0 হতে হবে।
সুতরাং, ∣P−Q∣=0  ⟹  বা, P=Q|P - Q| = 0 \implies \text{বা, } P = Q
দেখা যাচ্ছে, দুটি ভেক্টরের লব্ধি শূন্য হওয়ার একমাত্র শর্ত হলো ভেক্টর দুটির মান সমান হতে হবে এবং তারা পরস্পর বিপরীত দিকে ক্রিয়াশীল হতে হবে। যেহেতু প্রশ্নের ভেক্টর দুটি অসমান বলা হয়েছে, তাই তাদের লব্ধি কখনোই শূন্য হতে পারে না।

১ম ছাত্রের ক্ষেত্রে, মাঝি OBOB বরাবর রওয়ানা দিয়ে CC বিন্দুতে পৌঁছায়। (অর্থাৎ, নৌকাটি স্রোতের সাথে লম্বভাবে যাত্রা শুরু করে)।
তাই, ১ম ছাত্রের নদী পার হতে প্রয়োজনীয় সময়,
tOC=নদীর প্রস্থনৌকার বেগ  ⟹  বা, tOC=du=210 h=0.2 ht_{OC} = \frac{\text{নদীর প্রস্থ}}{\text{নৌকার বেগ}} \implies \text{বা, } t_{OC} = \frac{d}{u} = \frac{2}{10}\text{ h} = 0.2\text{ h}
এই সময়ে স্রোতের কারণে নৌকাটি যে দূরত্ব অতিক্রম করে, তাই হলো BCBC দূরত্ব।
BC=স্রোতের বেগ×সময়=v×tOC=5×0.2 km  ⟹  ∴BC=1 km (Ans.)BC = \text{স্রোতের বেগ} \times \text{সময়} = v \times t_{OC} = 5 \times 0.2\text{ km} \implies \therefore BC = 1\text{ km (Ans.)}

অংশ ঘ　·　৪ নম্বর

ছাত্রত্রয় কী ক্লাসে যথা সময়ে পৌঁছাতে পারবে? গাণিতিকভাবে আলোচনা করো।

হিন্ট আগে নিজে চেষ্টা করো
পূর্ণ উত্তর চিত্র ও সমাধান

১ম ছাত্রের ক্ষেত্রে (O→CO \to C নৌকায়, C→BC \to B হেঁটে):
OO হতে CC তে যেতে সময়, tOC=0.2 ht_{OC} = 0.2\text{ h} (গ হতে প্রাপ্ত)
CC হতে BB তে হেঁটে যেতে সময়,
tCB, হাঁটা=BCvw  ⟹  বা, tCB, হাঁটা=1 km5.76 kmh−1  ⟹  tCB, হাঁটা=0.1736 ht_{CB,\,\text{হাঁটা}} = \frac{BC}{v_w} \implies \text{বা, } t_{CB,\,\text{হাঁটা}} = \frac{1\text{ km}}{5.76\text{ kmh}^{-1}} \implies t_{CB,\,\text{হাঁটা}} = 0.1736\text{ h}

মোট সময়, t1=tOC+tCB, হাঁটাt_1 = t_{OC} + t_{CB,\,\text{হাঁটা}}
বা, t1=0.2+0.1736 h=0.3736 h=0.3736×60 min  ⟹  ∴t1=22.42 min\text{বা, } t_1 = 0.2 + 0.1736\text{ h} = 0.3736\text{ h} = 0.3736 \times 60\text{ min} \implies \therefore t_1 = 22.42\text{ min}
যেহেতু, t1<25 mint_1 < 25\text{ min}, তাই ১ম ছাত্র যথাসময়ে পৌঁছাতে পারবে।

২য় ছাত্রের ক্ষেত্রে (O→CO \to C নৌকায়, C→BC \to B নৌকায়):
OO হতে CC তে যেতে সময়, tOC=0.2 ht_{OC} = 0.2\text{ h} (গ হতে প্রাপ্ত)
CC হতে BB তে নৌকায় যাওয়ার স্রোতের প্রতিকূলে যাত্রা করলে CC হতে BB তে নৌকায় যেতে সময়,
tCB, নৌকা=BCu−v=1 km5 kmh−1=0.2 ht_{CB,\,\text{নৌকা}} = \frac{BC}{u - v} = \frac{1\text{ km}}{5\text{ kmh}^{-1}} = 0.2\text{ h}

(ওপরের বক্স)

  • BCBC দূরত্ব, BC=1 kmBC = 1\text{ km} (গ হতে প্রাপ্ত)
  • স্রোতের প্রতিকূলে নৌকার বেগ, u−v=5 kmh−1u - v = 5\text{ kmh}^{-1}

মোট সময়, t2=tOC+tCB, নৌকাt_2 = t_{OC} + t_{CB,\,\text{নৌকা}}
বা, t2=0.2+0.2 h=0.4 h=0.4×60 min  ⟹  ∴t2=24 min\text{বা, } t_2 = 0.2 + 0.2\text{ h} = 0.4\text{ h} = 0.4 \times 60\text{ min} \implies \therefore t_2 = 24\text{ min}
যেহেতু, t2<25 mint_2 < 25\text{ min}, তাই ২য় ছাত্র যথাসময়ে পৌঁছাতে পারবে।

৩য় ছাত্রের ক্ষেত্রে (O→BO \to B সরাসরি):
৩য় ছাত্রকে সরাসরি BB বিন্দুতে পৌঁছাতে হলে নৌকাকে স্রোতের বিপরীতে (OAOA বরাবর) যাত্রা করতে হবে। এই ক্ষেত্রে লব্ধি বেগ RR নদীর প্রস্থ বরাবর কাজ করবে।
লব্ধি বেগ,
R=u2−v2=102−52=100−25=75  ⟹  ∴R=8.660 kmh−1R = \sqrt{u^2 - v^2} = \sqrt{10^2 - 5^2} = \sqrt{100 - 25} = \sqrt{75} \implies \therefore R = 8.660\text{ kmh}^{-1}
নদী পার হতে প্রয়োজনীয় সময়,
t3=dR=28.660 h=0.2309 h=0.2309×60 min  ⟹  ∴t3=13.85 mint_3 = \frac{d}{R} = \frac{2}{8.660}\text{ h} = 0.2309\text{ h} = 0.2309 \times 60\text{ min} \implies \therefore t_3 = 13.85\text{ min}
যেহেতু, t3<25 mint_3 < 25\text{ min}, তাই ৩য় ছাত্র যথাসময়ে পৌঁছাতে পারবে।
দেখা যাচ্ছে, ১ম ছাত্রের সময় 22.42 min22.42\text{ min}, ২য় ছাত্রের সময় 24 min24\text{ min} এবং ৩য় ছাত্রের সময় 13.85 min13.85\text{ min}। যেহেতু তিনজনের ক্ষেত্রেই প্রয়োজনীয় সময় 25 min25\text{ min} এর কম, সুতরাং ছাত্রত্রয় ক্লাসে যথা সময়ে পৌঁছাতে পারবে।
