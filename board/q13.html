  • দুটি সমান্তরাল পাড়ের মাঝে ড্যাশ চিহ্নিত নদী।

  • PP থেকে QQ বরাবর খাড়া প্রস্থরেখা PQPQ আঁকা আছে।
  • PP বিন্দু থেকে ওপর-বামদিকে তির্যকভাবে PSPS তীরচিহ্ন দেখানো হয়েছে, যা নিচের পাড়ের ডানদিকের (স্রোতের দিক) সাথে 100∘100^\circ কোণ তৈরি করেছে।
  • নদীর নিচে লেখা: স্রোতের বেগ = 3 kmh⁻¹।

উদ্দীপক:

ক. সমাধান দেখো ১ নম্বর

যে গাণিতিক চিহ্নের দ্বারা একটি ভেক্টর রাশিকে অন্য একটি স্কেলার বা ভেক্টর রাশিতে রূপান্তর করা যায় বা কোনো পরিবর্তনশীল ভেক্টর রাশির ব্যাখ্যা দেয়া যায় তাই ভেক্টর অপারেটর।

খ. সমাধান দেখো ২ নম্বর

কোনো বস্তুকণাকে বৃত্তাকার পথে গতিশীল রাখতে কেন্দ্রের দিকে যে বল প্রয়োগ করতে হয় তাকে কেন্দ্রমুখী বল বলা হয়। বৃত্তাকার পথে ঘূর্ণনরত বস্তু কণার ভর mm, রৈখিক বেগ vv, কৌণিক বেগ ω\omega এবং বৃত্তাকার পথের ব্যাসার্ধ rr হলে, কেন্দ্রমুখী বল, Fc=mv2r=mω2rF_c = \frac{mv^2}{r} = m\omega^2 r
কেন্দ্রমুখী বলের সমীকরণ অনুযায়ী কেন্দ্রমুখী বল ৩টি বিষয়ের উপর নির্ভর করে:

  • i. বস্তু কণার ভর (mm)
  • ii. বস্তু কণার রৈখিক বেগ (vv) বা কৌণিক বেগ (ω\omega)
  • iii. বস্তু কণাটি যে বৃত্তাকার পথে ঘুরে, তার ব্যাসার্ধ (rr)।
গ. সমাধান দেখো ৩ নম্বর

ধরি, লব্ধি বেগ স্রোতের বেগের সাথে θ\theta কোণ উৎপন্ন করে।
∴tan⁡θ=vsin⁡αu+vcos⁡α\therefore \tan\theta = \frac{v\sin\alpha}{u + v\cos\alpha}
বা, tan⁡θ=5sin⁡100∘3+5cos⁡100∘\text{বা, } \tan\theta = \frac{5\sin 100^\circ}{3 + 5\cos 100^\circ}
বা, tan⁡θ=2.31\text{বা, } \tan\theta = 2.31
বা, θ=tan⁡−1(2.31)\text{বা, } \theta = \tan^{-1}(2.31)
∴θ=66.59∘\therefore \theta = 66.59^\circ

(ডান পাশের বক্স)
এখানে,

  • স্রোতের বেগ, u=3 kmh−1u = 3\text{ kmh}^{-1}
  • নৌকার বেগ, v=5 kmh−1v = 5\text{ kmh}^{-1}
  • স্রোত ও নৌকার মধ্যবর্তী কোণ α=100∘\alpha = 100^\circ

চিত্রের বিবরণ (১৩ নং উত্তর - গ):

  • দুটি সমান্তরাল নদীর পাড়: নিচে PP, ওপরে ঠিক বিপরীতে QQ এবং ডানে MM।
  • PQPQ খাড়া সরলরেখা এবং PMPM ড্যাশ-ড্যাশ তির্যক রেখা (লব্ধি পথ)।
  • নিচের পাড় (ডানদিক) ও PMPM এর মধ্যবর্তী কোণ θ=66.59∘\theta = 66.59^\circ এবং PQPQ ও PMPM এর মধ্যবর্তী কোণ ϕ\phi চিহ্নিত।

চিত্রানুযায়ী, ϕ=90∘−66.59∘=23.41∘\phi = 90^\circ - 66.59^\circ = 23.41^\circ
ΔPQM\Delta PQM-এ
tan⁡ϕ=QMPQ\tan\phi = \frac{QM}{PQ}
বা, tan⁡23.41∘=QM2\text{বা, } \tan 23.41^\circ = \frac{QM}{2}
∴QM=0.866 km=866 m (Ans.)\therefore QM = 0.866\text{ km} = 866\text{ m (Ans.)}

(ডান পাশের বক্স)
এখানে,

  • নদীর প্রস্থ, PQ=2 kmPQ = 2\text{ km}
ঘ. সমাধান দেখো ৪ নম্বর

PSPS বরাবর নৌকা চালিয়ে MM বিন্দুতে পৌঁছার
প্রয়োজনীয় সময়, t1=dvsin⁡α=25sin⁡100∘=0.406 h=24.35 min\text{প্রয়োজনীয় সময়, } t_1 = \frac{d}{v\sin\alpha} = \frac{2}{5\sin 100^\circ} = 0.406\text{ h} = 24.35\text{ min}

(ডান পাশের বক্স)
এখানে,

  • নদীর প্রস্থ, d=2 kmd = 2\text{ km}
  • নৌকার বেগ, v=5 kmh−1v = 5\text{ kmh}^{-1}
  • কোণ, α=100∘\alpha = 100^\circ

PP থেকে স্রোতহীন অবস্থায় নৌকা চালিয়ে QQ তে পৌঁছানোর সময়:
এক্ষেত্রে নৌকার বেগ হবে PQPQ বরাবর
অর্থাৎ, α=90∘\alpha = 90^\circ
∴প্রয়োজনীয় সময়, t2=25sin⁡90∘=0.4 h=24 min\therefore \text{প্রয়োজনীয় সময়, } t_2 = \frac{2}{5\sin 90^\circ} = 0.4\text{ h} = 24\text{ min}
∴t2<t1\therefore t_2 < t_1
সময়ের পার্থক্য=t1−t2=24.35−24=0.35 min=21 s\text{সময়ের পার্থক্য} = t_1 - t_2 = 24.35 - 24 = 0.35\text{ min} = 21\text{ s}
সুতরাং, PSPS বরাবর নৌকা চালিয়ে 'M' বিন্দুতে পৌঁছার সময় এবং PP থেকে স্রোতহীন অবস্থায় সরাসরি নৌকা চালিয়ে QQ-তে পৌঁছার সময়ের পার্থক্য 21 s21\text{ s}।
