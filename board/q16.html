অংশ খ　·　২ নম্বর

ভেক্টর যোগের সামান্তরিক সূত্র বিনিময় সূত্র মেনে চলে।— ব্যাখ্যা করো।

হিন্ট আগে নিজে চেষ্টা করো
পূর্ণ উত্তর চিত্র ও সমাধান

P⃗\vec{P} ও Q⃗\vec{Q} ভেক্টরদ্বয় OACBOACB সামান্তরিকের OAOA ও OBOB বাহু দ্বারা নির্দেশ করা হলে, OCOC কর্ণ তাদের লব্ধি প্রকাশ করবে।
OAOA ও BCBC সমান ও সমান্তরাল বলে OA→=BC→=P⃗\overrightarrow{OA} = \overrightarrow{BC} = \vec{P}
অনুরূপভাবে, OB→=AC→=Q⃗\overrightarrow{OB} = \overrightarrow{AC} = \vec{Q}

  • একটি OACBOACB সামান্তরিক আঁকা হয়েছে: নিচের ভূমি OA→=P⃗\overrightarrow{OA} = \vec{P} (ডানদিকে), বাম পাশের বাহু OB→=Q⃗\overrightarrow{OB} = \vec{Q} (ওপর-ডানদিকে), ওপরের বাহু BC→=P⃗\overrightarrow{BC} = \vec{P} (ডানদিকে), ডান পাশের বাহু AC→=Q⃗\overrightarrow{AC} = \vec{Q} (ওপর-ডানদিকে) এবং কর্ণ OC→\overrightarrow{OC} (OO থেকে CC পর্যন্ত)।

ΔOAC\Delta OAC হতে OA→+AC→=OC→\overrightarrow{OA} + \overrightarrow{AC} = \overrightarrow{OC}
∴P⃗+Q⃗=R⃗\therefore \vec{P} + \vec{Q} = \vec{R}
আবার, ΔOBC\Delta OBC হতে OB→+BC→=OC→\overrightarrow{OB} + \overrightarrow{BC} = \overrightarrow{OC}
∴Q⃗+P⃗=R⃗\therefore \vec{Q} + \vec{P} = \vec{R}
অতএব, P⃗+Q⃗=Q⃗+P⃗\vec{P} + \vec{Q} = \vec{Q} + \vec{P}, যা মূলত বিনিময় সূত্র।
সুতরাং ভেক্টর যোগের সামান্তরিক সূত্র বিনিময় সূত্র মেনে চলে।

অংশ গ　·　৩ নম্বর

সোহেলের ক্ষেত্রে নৌকার বেগ ও স্রোতের বেগের লব্ধি বেগের মান নির্ণয় করো।

হিন্ট আগে নিজে চেষ্টা করো
পূর্ণ উত্তর চিত্র ও সমাধান

যেহেতু, লব্ধি ও স্রোতের মধ্যবর্তী কোণ θ=90∘\theta = 90^\circ
সুতরাং লব্ধি বেগের দিক,
tan⁡θ=vsin⁡αu+vcos⁡α\tan\theta = \frac{v\sin\alpha}{u + v\cos\alpha}
বা, tan⁡90∘=8sin⁡α4+8cos⁡α\text{বা, } \tan 90^\circ = \frac{8\sin\alpha}{4 + 8\cos\alpha}
বা, 4+8cos⁡α=0\text{বা, } 4 + 8\cos\alpha = 0
বা, α=cos⁡−1(−48)\text{বা, } \alpha = \cos^{-1}\left(-\frac{4}{8}\right)
∴α=120∘\therefore \alpha = 120^\circ
লব্ধি বেগ, R=u2+v2+2uvcos⁡α\text{লব্ধি বেগ, } R = \sqrt{u^2 + v^2 + 2uv\cos\alpha}
=42+82+2×4×8×cos⁡120∘= \sqrt{4^2 + 8^2 + 2 \times 4 \times 8 \times \cos 120^\circ}
=43 kmh−1 (Ans.)= 4\sqrt{3}\text{ kmh}^{-1}\text{ (Ans.)}

হিন্ট আগে নিজে চেষ্টা করো
পূর্ণ উত্তর চিত্র ও সমাধান

'গ' থেকে প্রাপ্ত, স্রোতের বেগ ও সোহেলের নৌকার বেগের মধ্যবর্তী কোণ, αs=120∘\alpha_s = 120^\circ
সোহেলের নদী পার হতে প্রয়োজনীয়
সময়, t=dvssin⁡αs\text{সময়, } t = \frac{d}{v_s\sin\alpha_s}
বা, 600=d209sin⁡120∘\text{বা, } 600 = \frac{d}{\frac{20}{9}\sin 120^\circ}
∴d=1154.7 m=AD\therefore d = 1154.7\text{ m} = AD

এখন, রোহানের লব্ধি বেগ ACAC বরাবর, যা স্রোতের দিকের সাথে θR\theta_R কোণ উৎপন্ন করে (ধরি)।
tan⁡θR=vRsin⁡αRu+vRcos⁡αR\tan\theta_R = \frac{v_R\sin\alpha_R}{u + v_R\cos\alpha_R}
বা, tan⁡θR=259sin⁡90∘109+259cos⁡90∘\text{বা, } \tan\theta_R = \frac{\frac{25}{9}\sin 90^\circ}{\frac{10}{9} + \frac{25}{9}\cos 90^\circ}
∴θR=tan⁡−1(2510)=68.20∘\therefore \theta_R = \tan^{-1}\left(\frac{25}{10}\right) = 68.20^\circ
