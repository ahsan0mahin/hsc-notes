Question and stimulus

Two boatmen start at A, each at 16 km/h relative to water. They aim 30° and 60° upstream of the perpendicular AB respectively. Width is 2 km; the current is 8 km/h.

  1. (a)

    What is a scalar field?

    1 mark
  2. (b)

    Is a reciprocal vector collinear with its original?

    2 marks
  3. (c)

    Find the first boatman’s resultant velocity.

    3 marks
  4. (d)

    Which boatman travels the shorter distance?

    4 marks

Reading the diagram

AB runs straight across; the two headings lie 30° and 60° upstream of AB. Both boatmen’s horizontal components therefore oppose the current.

Try it yourself

Part a · 1 mark

What is a scalar field?

Hint Try it first

What information is needed at each position?

Full solution Diagram and explanation

A scalar field assigns a single scalar value to each point, as in a temperature distribution.

Part b · 2 marks

Is a reciprocal vector collinear with its original?

Hint Try it first

Compare directions rather than magnitudes.

Full solution Diagram and explanation

Yes. The reciprocal is a positive scalar multiple of the nonzero original, so their lines are parallel.

Part c · 3 marks

Find the first boatman’s resultant velocity.

Hint Try it first

Express the upstream component using the angle measured from AB.

Full solution Diagram and explanation

(vx,vy)=(8−16sin⁡30∘,16cos⁡30∘)(v_x,v_y)=(8-16\sin30^\circ,16\cos30^\circ)

The downstream component is 8−16 sin30°=0. The crossing speed is 16 cos30°=8√3 km/h.

Part d · 4 marks

Which boatman travels the shorter distance?

Hint Try it first

Calculate the net along-bank component of each boat; does either track have no drift?

Full solution Diagram and explanation

8−16sin⁡60∘≠08-16\sin60^\circ\ne0

The first travels exactly 2 km. The second has nonzero drift 8−16 sin60°, so his diagonal path is longer.

Source notes and corrections

The first resultant is 8√3 km/h (about 3.85 m/s), not 8 m/s.
