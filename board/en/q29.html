Try it yourself

Part a · 1 mark

Define coplanar vectors.

Hint Try it first

Think of translating free arrows to a common origin.

Full solution Diagram and explanation

Their directions can all lie in one plane; the scalar triple product of any three is zero.

Part b · 2 marks

How should a boat be steered to land directly opposite?

Hint Try it first

Consider the component parallel to the banks.

Full solution Diagram and explanation

Aim upstream so that the upstream component of the boat’s velocity relative to water cancels the current.

Part c · 3 marks

Find m.

Hint Try it first

Multiply matching components and use the stated perpendicularity.

Full solution Diagram and explanation

8−4m=08-4m=0

P·Q=8−4m=0, hence m=2.

Part d · 4 marks

Does a minimum-time crossing cover more distance than the width? Verify numerically.

Hint Try it first

Find the width from the direct-crossing time. Compare the diagonal path on the fastest crossing with that width.

Full solution Diagram and explanation

SD=38+1838\frac{S}{D}=\frac{\sqrt{38+18}}{\sqrt{38}}

The speeds are √38 and √18. The direct crossing speed is √20; the minimum-time path-to-width ratio is √56/√38≈1.214. The route is longer.

Source notes and corrections

The two-minute crossing time must be converted to units consistent with the chosen speed units. The path-to-width ratio is independent of those units.
