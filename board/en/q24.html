Part a · 1 mark

Define the position (radius) vector.

Hint Try it first

Choose an origin first.

Full solution Diagram and explanation

It is the directed displacement from the chosen origin O to the point P, r⃗=OP→\vec r=\overrightarrow{OP}.

Part b · 2 marks

Can two nonzero vectors have zero dot product?

Hint Try it first

Look at the angular factor.

Full solution Diagram and explanation

Yes: for perpendicular nonzero vectors, cos 90° = 0.

Part c · 3 marks

Find div P at (−1,1,1).

Hint Try it first

When differentiating a component, hold the other coordinates fixed.

Full solution Diagram and explanation

∇⋅P⃗=9y2+8y\nabla\cdot\vec P=9y^2+8y

The divergence is 9y2+8y9y^2+8y, which equals 17.

Part d · 4 marks

Is P irrotational? Verify.

Hint Try it first

Try the three curl components before deciding whether the whole field is irrotational.

Full solution Diagram and explanation

∇×P⃗=(2−2x,5−9x2,2z−18xy)\nabla\times\vec P=(2-2x,5-9x^2,2z-18xy)

The curl has components (2−2x,5−9x2,2z−18xy)(2-2x,5-9x^2,2z-18xy). It does not vanish identically, so the field is not irrotational.
