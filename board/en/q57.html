Question and stimulus

A boat sets out at 120° to the 3 km/h current of a river 5 km wide. It lands 722 m from the point directly opposite.

  1. (a)

    What is angular momentum?

    1 mark
  2. (b)

    Which is larger: limiting static or kinetic friction?

    2 marks
  3. (c)

    How long would a direct crossing take?

    3 marks
  4. (d)

    Find the boat speed consistent with the stated landing position.

    4 marks

Try it yourself

Part a · 1 mark

What is angular momentum?

Hint Try it first

Measure position from the point about which rotation is considered.

Full solution Diagram and explanation

Angular momentum is the moment of linear momentum, L⃗=r⃗×p⃗\vec L=\vec r\times\vec p.

Part b · 2 marks

Which is larger: limiting static or kinetic friction?

Hint Try it first

Compare the force immediately before sliding with that during sliding.

Full solution Diagram and explanation

For typical dry surfaces the limiting static coefficient exceeds the kinetic coefficient. At the same normal load the limiting friction is larger.

Part c · 3 marks

How long would a direct crossing take?

Hint Try it first

Use the speed from part (d), not the original 120° heading, for a direct landing.

Full solution Diagram and explanation

t=5u2−32 ht=\frac{5}{\sqrt{u^2-3^2}}\,\mathrm h

Using the speed found in (d), the direct crossing component is √(4.80²−3²)≈3.75 km/h. Time is about 1.33 h.

Part d · 4 marks

Find the boat speed consistent with the stated landing position.

Hint Try it first

The ratio of downstream offset to width equals the ratio of the two ground velocity components.

Full solution Diagram and explanation

u=152.5+0.722sin⁡120∘ km/hu=\frac{15}{2.5+0.722\sin120^\circ}\,\mathrm{km/h}

Taking the displacement to be downstream as in the printed solution, 0.722=(3+ucos⁡120∘)5/(usin⁡120∘)0.722=(3+u\cos120^\circ)5/(u\sin120^\circ). Thus u≈4.80 km/h.

Source notes and corrections

The landing description is ambiguous. The calculation uses a 0.722 km downstream offset. Squaring 4.8 gives 23.04, not 64.
