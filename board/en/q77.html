Part a · 1 mark

What is a physical quantity?

Hint Try it first

How would you report a measurement?

Full solution Diagram and explanation

It is a measurable property expressed by a numerical value and a unit.

Part b · 2 marks

Why is a trolley handle long?

Hint Try it first

At a fixed hand height compare the angle to the ground.

Full solution Diagram and explanation

A longer handle can make a smaller angle to the horizontal. The same pull then has a greater forward component Fcos⁡θF\cos\theta.

Part c · 3 marks

Find m if α=90°.

Hint Try it first

For a 90° angle, which algebraic product must vanish?

Full solution Diagram and explanation

2m+56=02m+56=0

Perpendicular vectors have zero dot product: 2m+6+50=0, hence m=−28.

Part d · null marks

Do these vectors obey commutation for their cross product?

Hint Try it first

Compare the two products by reversing the order, and rule out a zero cross product.

Full solution Diagram and explanation

B⃗×A⃗=−(A⃗×B⃗)≠A⃗×B⃗\vec B\times\vec A=-(\vec A\times\vec B)\ne\vec A\times\vec B

Both vectors are nonzero and perpendicular. Their cross product is nonzero, and reversing the order reverses its direction rather than leaving it unchanged.

Source notes and corrections

For a longer trolley handle, angle comparisons assume a fixed hand height. The vertical component also changes and can affect friction.
