ক. সমাধান দেখো ১ নম্বর

যে ভেক্টর রাশির মান এক একক তাকে একক ভেক্টর বলে।

খ. সমাধান দেখো ২ নম্বর

যদি V⃗(x,y,z)\vec{V}(x, y, z) একটি ত্রিমাত্রিক স্থানাঙ্কে ভেক্টর ক্ষেত্র হয় তবে ভেক্টর অপারেটর ∇⃗\vec{\nabla} এবং ভেক্টর পয়েন্ট ফাংশন V⃗\vec{V} এর স্কেলার বা ডট গুণফলকে ভেক্টর ক্ষেত্র V⃗\vec{V} এর ডাইভারজেন্স বলে।
অর্থাৎ divV⃗=∇⃗⋅V⃗\text{div}\vec{V} = \vec{\nabla} \cdot \vec{V}।
এখানে, ∇⃗=i^δδx+j^δδy+k^δδz\vec{\nabla} = \hat{i}\frac{\delta}{\delta x} + \hat{j}\frac{\delta}{\delta y} + \hat{k}\frac{\delta}{\delta z}
যেহেতু, ∇⃗⋅V⃗\vec{\nabla} \cdot \vec{V} একটি স্কেলার রাশি, তাই ডাইভারজেন্স একটি অদিক রাশি।

গ. সমাধান দেখো ৩ নম্বর

PQ→=(−2−4)i^+(4+2)j^+(5−3)k^\overrightarrow{PQ} = (-2 - 4)\hat{i} + (4 + 2)\hat{j} + (5 - 3)\hat{k}
=−6i^+6j^+2k^= -6\hat{i} + 6\hat{j} + 2\hat{k}
QR→=(−1+2)i^+(2−4)j^+(−2−5)k^\overrightarrow{QR} = (-1 + 2)\hat{i} + (2 - 4)\hat{j} + (-2 - 5)\hat{k}
=i^−2j^−7k^= \hat{i} - 2\hat{j} - 7\hat{k}

=i^[{6×(−7)}−{2×(−2)}]−j^[{(−6)×(−7)}−{2×1}]+k^[{(−6)×(−2)}−{6×1}]= \hat{i}[\{6 \times (-7)\} - \{2 \times (-2)\}] - \hat{j}[\{(-6) \times (-7)\} - \{2 \times 1\}] + \hat{k}[\{(-6) \times (-2)\} - \{6 \times 1\}]

∴∣PQ→×QR→∣=(−38)2+(−40)2+62=2770\therefore |\overrightarrow{PQ} \times \overrightarrow{QR}| = \sqrt{(-38)^2 + (-40)^2 + 6^2} = 2\sqrt{770}

ঘ. সমাধান দেখো ৪ নম্বর

'গ' হতে পাই,
PQ→=−6i^+6j^+2k^\overrightarrow{PQ} = -6\hat{i} + 6\hat{j} + 2\hat{k}
QR→=i^−2j^−7k^\overrightarrow{QR} = \hat{i} - 2\hat{j} - 7\hat{k}
এখন,
PR→=(−1−4)i^+(2+2)j^+(2−3)k^\overrightarrow{PR} = (-1 - 4)\hat{i} + (2 + 2)\hat{j} + (2 - 3)\hat{k}
[বইয়ের মুদ্রণ ত্রুটি: R এর z-স্থানাঙ্ক -2 এর বদলে 2 ব্যবহৃত হয়েছে, তবে ফলাফলে লেখা হয়েছে -5i + 4j - k (অর্থাৎ (-2-3) হলে -5k হওয়ার কথা ছিল)]
=−5i^+4j^−k^= -5\hat{i} + 4\hat{j} - \hat{k}
∴∣PQ→∣=(−6)2+62+22=219\therefore |\overrightarrow{PQ}| = \sqrt{(-6)^2 + 6^2 + 2^2} = 2\sqrt{19}
∣QR→∣=12+(−2)2+(−7)2=36|\overrightarrow{QR}| = \sqrt{1^2 + (-2)^2 + (-7)^2} = 3\sqrt{6}
∣PR→∣=(−5)2+42+(−1)2=42|\overrightarrow{PR}| = \sqrt{(-5)^2 + 4^2 + (-1)^2} = \sqrt{42}
এখানে, ∣QR→∣2+∣PR→∣2=(36)2+(42)2=96|\overrightarrow{QR}|^2 + |\overrightarrow{PR}|^2 = (3\sqrt{6})^2 + (\sqrt{42})^2 = 96
এবং ∣PQ→∣2=(219)2=76|\overrightarrow{PQ}|^2 = (2\sqrt{19})^2 = 76
∴∣PQ→∣2≠∣QR→∣2+∣PR→∣2\therefore |\overrightarrow{PQ}|^2 \neq |\overrightarrow{QR}|^2 + |\overrightarrow{PR}|^2
∴\therefore উদ্দীপকের বিন্দু তিনটি একটি সমকোণী ত্রিভুজ গঠন করবে না।
