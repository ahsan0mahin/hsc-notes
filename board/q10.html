যশোর বোর্ড ২০২৫

প্রশ্ন ১০ / ১৫　 ·　 মূল প্রশ্ন নং ৪

চিত্রের বিবরণ (প্রশ্ন ১০ - উদ্দীপক):

  • পাশাপাশি দুটি ভেক্টর কোণ চিত্র দেওয়া আছে:
    1. বাম চিত্র: আনুভূমিক ডানদিকে A⃗\vec{A} ভেক্টর এবং একই পাদবিন্দু থেকে ওপর-ডানদিকে তির্যকভাবে B⃗\vec{B} ভেক্টর। এদের মধ্যবর্তী কোণ θ1\theta_1।
    2. ডান চিত্র: আনুভূমিক ডানদিকে A⃗+B⃗\vec{A} + \vec{B} ভেক্টর এবং একই পাদবিন্দু থেকে ওপর-ডানদিকে তির্যকভাবে A⃗−B⃗\vec{A} - \vec{B} ভেক্টর। এদের মধ্যবর্তী কোণ θ2\theta_2।

উদ্দীপক:
A⃗=2i^−2j^+2k^\vec{A} = 2\hat{i} - 2\hat{j} + 2\hat{k} এবং B⃗=i^−3j^+6k^\vec{B} = \hat{i} - 3\hat{j} + 6\hat{k}

প্রশ্নসমূহ:

  • ক. কার্ল কী? (১)
  • খ. দুটি সমমানের ভেক্টরের লব্ধি তাদের অন্তর্গত কোণকে সমদ্বিখণ্ডিত করে – ব্যাখ্যা করো। (২)
  • গ. ভেক্টর B⃗\vec{B} বরাবর A⃗\vec{A} এর লম্ব অভিক্ষেপ নির্ণয় করো। (৩)
  • ঘ. উদ্দীপকের আলোকে θ1=θ2\theta_1 = \theta_2 হওয়া সম্ভব কি-না গাণিতিক বিশ্লেষণের মাধ্যমে তোমার মতামত দাও। (৪)

চিত্রে বুঝে নাও

নিজে চেষ্টা করে উত্তর মেলাও

ক. সমাধান দেখো ১ নম্বর

কোন ভেক্টর ক্ষেত্রের ঘূর্ণনের সাথে সম্পর্কিত এমন একটি ভেক্টর রাশি যা ঐ ভেক্টর ক্ষেত্রের কোনো একটি বিন্দুর চতুর্দিকে প্রতি একক ক্ষেত্রফলে ভেক্টরটির সর্বোচ্চ লাইন ইন্টিগ্র্যাল প্রকাশ করে তাই কার্ল।

খ. সমাধান দেখো ২ নম্বর

মনে করি, α\alpha কোণে ক্রিয়াশীল দুটি সমমানের P⃗\vec{P} এর লব্ধি R⃗\vec{R}, P⃗\vec{P} এর সাথে θ\theta কোণ উৎপন্ন করেছে।
∴tan⁡θ=Psin⁡αP+Pcos⁡α=sin⁡α1+cos⁡α\therefore \tan\theta = \frac{P\sin\alpha}{P + P\cos\alpha} = \frac{\sin\alpha}{1 + \cos\alpha}
=2sin⁡α2cos⁡α22cos⁡2α2=tan⁡α2= \frac{2\sin\frac{\alpha}{2}\cos\frac{\alpha}{2}}{2\cos^2\frac{\alpha}{2}} = \tan\frac{\alpha}{2}
∴θ=α2\therefore \theta = \frac{\alpha}{2}
অর্থাৎ, দুটি সমমানের ভেক্টরের লব্ধি তাদের অন্তর্গত কোণকে সমদ্বিখণ্ডিত করে।

(১০ নং প্রশ্নের উত্তর - গ ও ঘ)

গ. সমাধান দেখো ৩ নম্বর

ভেক্টর B⃗\vec{B} বরাবর ভেক্টর A⃗\vec{A} এর লম্ব অভিক্ষেপ হলো—
Acos⁡θ=A⃗⋅B⃗BA\cos\theta = \frac{\vec{A} \cdot \vec{B}}{B}
=(2i^−2j^+2k^)⋅(i^−3j^+6k^)12+(−3)2+62= \frac{(2\hat{i} - 2\hat{j} + 2\hat{k}) \cdot (\hat{i} - 3\hat{j} + 6\hat{k})}{\sqrt{1^2 + (-3)^2 + 6^2}}
=2046=2.949 (Ans.)= \frac{20}{\sqrt{46}} = 2.949\text{ (Ans.)}

(ডান পাশের বক্স)
এখানে,
A⃗=2i^−2j^+2k^\vec{A} = 2\hat{i} - 2\hat{j} + 2\hat{k}
B⃗=i^−3j^+6k^\vec{B} = \hat{i} - 3\hat{j} + 6\hat{k}

ঘ. সমাধান দেখো ৪ নম্বর

উদ্দীপক অনুসারে,
A⃗+B⃗=2i^−2j^+2k^+i^−3j^+6k^=3i^−5j^+8k^\vec{A} + \vec{B} = 2\hat{i} - 2\hat{j} + 2\hat{k} + \hat{i} - 3\hat{j} + 6\hat{k} = 3\hat{i} - 5\hat{j} + 8\hat{k}
A⃗−B⃗=(2i^−2j^+2k^)−(i^−3j^+6k^)=i^+j^−4k^\vec{A} - \vec{B} = (2\hat{i} - 2\hat{j} + 2\hat{k}) - (\hat{i} - 3\hat{j} + 6\hat{k}) = \hat{i} + \hat{j} - 4\hat{k}

(ডান পাশের বক্স)
এখানে,
A⃗=2i^−2j^+2k^\vec{A} = 2\hat{i} - 2\hat{j} + 2\hat{k}
B⃗=i^−3j^+6k^\vec{B} = \hat{i} - 3\hat{j} + 6\hat{k}

এখানে, cos⁡θ1=A⃗⋅B⃗AB\cos\theta_1 = \frac{\vec{A} \cdot \vec{B}}{AB}
=(2i^−2j^+2k^)⋅(i^−3j^+6k^)22+(−2)2+2212+(−3)2+62= \frac{(2\hat{i} - 2\hat{j} + 2\hat{k}) \cdot (\hat{i} - 3\hat{j} + 6\hat{k})}{\sqrt{2^2 + (-2)^2 + 2^2}\sqrt{1^2 + (-3)^2 + 6^2}}
=202138=0.851= \frac{20}{2\sqrt{138}} = 0.851
∴θ1=cos⁡−1(0.851)=31.65∘\therefore \theta_1 = \cos^{-1}(0.851) = 31.65^\circ

আবার,
cos⁡θ2=(A⃗+B⃗)⋅(A⃗−B⃗)∣A⃗+B⃗∣∣A⃗−B⃗∣\cos\theta_2 = \frac{(\vec{A} + \vec{B}) \cdot (\vec{A} - \vec{B})}{|\vec{A} + \vec{B}||\vec{A} - \vec{B}|}
=(3i^−5j^+8k^)⋅(i^+j^−4k^)32+(−5)2+8212+12+(−4)2= \frac{(3\hat{i} - 5\hat{j} + 8\hat{k}) \cdot (\hat{i} + \hat{j} - 4\hat{k})}{\sqrt{3^2 + (-5)^2 + 8^2}\sqrt{1^2 + 1^2 + (-4)^2}}
=−3442=−0.809= \frac{-34}{42} = -0.809
∴θ2=cos⁡−1(−0.809)=144.049∘\therefore \theta_2 = \cos^{-1}(-0.809) = 144.049^\circ
∴θ1≠θ2\therefore \theta_1 \neq \theta_2
অতএব, উপর্যুক্ত গাণিতিক বিশ্লেষণের আলোকে বলা যায় যে, θ1=θ2\theta_1 = \theta_2 হওয়া সম্ভব নয়।
